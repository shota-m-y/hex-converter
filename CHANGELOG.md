# Changelog

## 0.1.0

Initial release.

- Hover over a number literal to see it in decimal, hex, binary and octal, with signed and ASCII readings where they apply.
- Show the same popup for the selection or the value at the cursor with `Ctrl+Alt+H`.
- Replace the selection or the value at the cursor with a converted value (`Ctrl+Alt+J`, or the replace icon in the popup).
- Converter panel for numbers (8 / 16 / 32 / 64 bit, clickable bits) and text ⇄ ASCII codes.
- English and Japanese UI.
